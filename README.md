# Handleitung Generative KI und musikwissenschaftliches Arbeiten
Dieses Projekt hat zum Ziel, eine Handleitung für den Einsatz von generativer KI beim musikwissenschaftlichen
Arbeiten zu entwerfen. Den Text finden Sie [hier](entwurf.md). Ergänzungen und Korrekturen aller Art sind herzlich 
willkommen. Um Änderungen vorzuschlagen, öffnen Sie bitte einen Pull Request. Für Diskussionen können Issues
angelegt werden.
